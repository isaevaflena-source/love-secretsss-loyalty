# Love secretsss — программа лояльности

Кассовая система для магазина женской красоты и белья. Кассир ищет клиента по телефону, видит баланс, начисляет баллы за покупку или списывает их. Есть реестр операций и дашборд.

## Правила

- За покупку начисляется 10% от суммы, с округлением вниз до целого балла.
- 1 балл = 1 ₽ при списании.
- Дата и время операции фиксируются автоматически по московскому времени.
- Реестр и показатели хранятся в Google Таблице. Текущая версия рассчитана на одну кассу: одновременные списания с разных устройств требуют дополнительной блокировки.

## Структура

- `worker/page.html` — интерфейс кассы, реестра и аналитики.
- `worker/index.js` — API: чтение реестра и запись операций через подключение Google Drive в Sites.
- `scripts/build.sh` — сборка Worker в `dist/`.

Для локальной сборки нужны Node.js 22+ и Bash. Команды: `npm run build`, затем `npm run validate`. Для работы с реальными данными требуется приватный Sites проект с подключённым Google Drive и доступом к его таблице. Секреты в репозитории не хранятся.

Публичный репозиторий показывает исходный код. Рабочий сайт остаётся приватным, поскольку содержит телефоны клиентов и историю покупок.
