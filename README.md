# Love secretsss — программа лояльности

Кассовая система для магазина женской красоты и белья. Кассир ищет клиента по телефону, видит ФИО и баланс, начисляет баллы за покупку или списывает их. Владелец видит реестр, список клиентов и аналитику.

## Правила

- За покупку начисляется 10% от суммы, с округлением вниз до целого балла.
- 1 балл = 1 ₽ при списании.
- При первой операции для нового номера обязательно вводится ФИО.
- Списание доступно через 24 часа после последнего начисления и не может превышать текущий баланс.
- Дата и время операции фиксируются автоматически по московскому времени.
- Показатели аналитики фильтруются по датам; общий остаток баллов всегда показывается на текущий момент.

## Доступ

- **Кассир:** вход по имени «Кассир» и отдельному паролю. Доступны поиск клиента, баланс, начисление и списание.
- **Фатима · Владелец:** вход по своему email или имени «Фатима» и отдельному паролю. Доступны касса, реестр, аналитика и ссылка на Google Таблицу.

Пароли и ключ обмена с Google Таблицей хранятся в секретных переменных Sites. Запросы проверяются на сервере; ссылки на таблицу и полный реестр не отдаются роли кассира.

## Структура

- `worker/page.html` — интерфейс кассы, реестра и аналитики.
- `worker/client.js` — логика интерфейса и фильтр по датам.
- `worker/index.js` — API, сессии и проверка роли.
- `scripts/build.sh` — сборка Worker в `dist/`.

Для локальной сборки нужны Node.js 22+ и Bash. Команды: `npm run build`, затем `npm run validate`. Для работы с реальными данными нужны секретные переменные Sites: `CASHIER_PASSWORD`, `OWNER_PASSWORD`, `SESSION_SECRET`, `BRIDGE_URL`, `BRIDGE_SECRET`. Google Apps Script запускается от имени владельца таблицы и проверяет серверный ключ перед чтением и записью. Секреты в репозитории не хранятся.

Публичный репозиторий показывает исходный код. Рабочий сайт доступен по ссылке, но операции и данные клиентов требуют входа.
