# Love secretsss — программа лояльности V3.0

Рабочий сайт: https://loyalty-ledger-20261123.workspace-426929.chatgpt.site

## Возможности

- Касса: поиск по телефону, ФИО при первой покупке, начисление и списание баллов.
- Для всех покупок начисляется 10% баллами. Клиент может войти сразу после первой покупки. Каждое начисление становится доступным к списанию через 24 часа, ранее доступные баллы остаются доступными.
- Списание не превышает доступные баллы и общий баланс.
- Клиентский вход без пароля по номеру, который уже есть в реестре. Клиент видит карту, баланс, уровень и новости клуба. Касса и реестр ему недоступны.
- Карта устанавливается на главный экран телефона как веб-приложение. Для нативного Apple Wallet или Google Wallet нужны отдельные учётные записи эмитента и сертификаты.
- Владелец видит реестр, аналитику с периодом, уровни клиентов и может публиковать новости всем или выбранному уровню.
- Операции и уведомления хранятся в отдельных листах Google Таблицы. Apps Script выполняет запись от имени владельца; сайт обращается к нему только с серверным секретом.

## Уровни

Уровень определяется общей суммой покупок с начислением. Уровни нужны для карты, подарков и адресных новостей; ставка начисления одинакова для всех.

| Общая сумма покупок | Уровень | Начисление |
|---|---|---|
| До 5 000 ₽ | Леди | 10% |
| От 5 000 до 14 999,99 ₽ | Принцесса | 10% |
| От 15 000 до 29 999,99 ₽ | Королева | 10% |
| От 30 000 ₽ | Императрица | 10%, ежемесячный подарок, приоритетные новости |

Баллы округляются вниз до целого числа. 1 балл = 1 ₽ при списании.

## Доступ

Пароли сотрудников и владельца, секрет сессий и ключ Apps Script задаются переменными окружения сайта. В исходниках их нет. Вход клиента только по известному номеру — требование продукта; для защиты от входа по чужому известному номеру в будущем нужен код подтверждения по SMS.

## Сборка

Нужен Node.js 22+ и Bash. `npm run build` создаёт `dist/server/index.js`, `npm run validate` проверяет артефакт. Конфигурация хостинга находится в `.openai/hosting.json`.
